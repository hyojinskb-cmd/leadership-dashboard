# Leadership Lens (리더십 렌즈)

팀장 리더십 역량 강화 및 팀 관리를 위한 AI 대시보드입니다.

## 🚀 로컬 PC에서 실행하기

파일 다운로드가 완료되었다면, 다음 단계를 따라 실행하세요.

1. **패키지 설치**
   터미널(CMD/Powershell)을 열고 프로젝트 폴더에서 다음 명령어 입력:
   ```bash
   npm install
   ```

2. **개발 서버 실행**
   ```bash
   npm run dev
   ```

3. **접속**
   브라우저에서 `http://localhost:5173` 으로 접속하세요.

4. **API Key 설정**
   - `.env.local` 파일을 열고 `API_KEY=당신의_GEMINI_KEY` 형식으로 저장하거나,
   - 앱 실행 후 '설정' 메뉴에서 키를 입력하세요.

## 📂 파일 구조 참고
현재 파일들이 프로젝트 최상위 폴더(Root)에 위치해 있습니다.
`index.html`이 `index.tsx`를 바로 참조하도록 설정되어 있습니다.

## 👋 팀원 공유용 데모 (웹 배포 시)
Vercel 등에 배포하면 API Key 없이도 '데모 모드'로 공유 가능합니다.
